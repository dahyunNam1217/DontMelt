# 1일차 — 게임 핵심 기획 및 게임 규칙 확정

## 오늘 한 일

개인 프로젝트 **Don't Melt**의 전체 게임 구조와 핵심 플레이 규칙을 구체화했다.

게임의 기본 구조는 플레이어가 다수의 NPC 사이에서 NPC처럼 행동하며 다른 플레이어를 속이고, 유물을 확보하여 승리하는 방식으로 확정했다.

주요 규칙:

- 2~4인 멀티플레이
- Listen Server
- 서버 권한형 판정
- 유물 수집 및 등록
- 플레이어 사망 및 Respawn
- 공격 / 방어 / 회피
- 스킬 시스템
- 관전 시스템
- NPC 최대 약 40명
- 최종적으로 한 명의 승자 결정

전투 판정 규칙:

- 공격 범위 안의 대상 전체 판정
- Player와 NPC가 동시에 범위 안에 있으면 모두 공격 처리
- Player는 사망 판정, NPC는 Stun 처리
- 공격 Trace는 벽을 통과하지 않음
- 방어는 전방 공격만 방어
- 방어 성공 후에도 방어 지속시간 유지
- 동시 공격은 서버에 먼저 도착한 판정을 우선 처리

## 복습 개념

- Server Authority
- Multiplayer Game Rule
- Hit Detection
- Trace / Collision
- State Machine
- Respawn
- Spectator
- Game Rule과 Gameplay Implementation 분리

## 오늘의 결과

구현 전에 애매했던 게임 규칙을 먼저 확정하여, 이후 코드에서 예외 처리 기준이 달라지는 문제를 방지했다.

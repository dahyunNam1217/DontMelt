# 2일차 — 전체 개발 단계 및 구현 순서 설계

## 오늘 한 일

전체 게임을 한 번에 구현하지 않고, 기능 의존성에 따라 단계적으로 개발하기로 결정했다.

```text
0. 기획 및 전체 책임 설계
1. C++ 프로젝트 골격
2. Match 기반
3. 이동·자세
4. 유물
5. 전투·리스폰
6. NPC AI
7. 퀘스트·이벤트
8. 스킬
9. 관전
10. UI
11. Steam·음성
12. 최적화
```

각 단계가 완료되지 않은 상태에서 다음 기능을 미리 구현하지 않는 방식을 적용하기로 했다.

## 복습 개념

- Incremental Development
- Feature Dependency
- Milestone
- YAGNI
- Regression Prevention
- Vertical / Layered Development

## 설계 원칙

```text
현재 필요한 기능
    ↓
필요한 책임 결정
    ↓
필요한 클래스 결정
    ↓
구현
    ↓
검증
    ↓
다음 단계
```

미래에 필요할 가능성만으로 클래스, Component, Enum, Struct 등을 미리 만들지 않는 방향으로 정리했다.

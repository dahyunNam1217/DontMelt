# Don't Melt — 게임 기획서

| 항목 | 내용 |
|---|---|
| 장르 | 2~4인 온라인 멀티플레이 / NPC 위장 / 유물 쟁탈 / 심리전 |
| 시점 | 1인칭·3인칭 전환, 기본 1인칭 |
| 경기 | 개인전, 정규 15분 + 최대 3분 연장전 |
| 환경 | Unreal Engine 5.5, C++, Listen Server, Steam |

## 1. 게임 개요

플레이어는 마녀의 저택에서 젤리 인간으로 변한 사람이다. 마을을 돌아다니는 NPC도 플레이어와 똑같은 외형을 쓴다. NPC인 척 돌아다니며 유물을 찾고, 다른 참가자의 정체를 행동으로 추리한다. 자기 상자에 유물을 먼저 모은 한 명만 탈출한다.

판별 단서는 이동·점프·달리기·자세·감정표현·공격·방어·발소리·상호작용·음성이다. 게임 화면에는 닉네임, 머리 위 아이콘, 외곽선, 상대 진영·유물 소지 표시를 두지 않는다. 서버가 허용하는 일시적인 위치 공개와 결과 화면만 예외다.

## 2. 핵심 규칙

| 항목 | 설정 | 비고 |
|---|---|---|
| 인원 | 2~4명 | 중도 참가 없음 |
| NPC | 시작 인원 × 15 | 4인 기준 60명. 초기 기획은 배율 10 |
| 정규 경기 | 900초 | 15분 |
| 연장전 | 180초 | 3분 |
| 리스폰 | 30초 | 사망 순간부터 서버 시간 기준 |
| 리스폰 보호 | 3초 | 공격·방어·상호작용·스킬 불가 |
| 공격 쿨다운 | 8초 | |
| 방어 | 지속 1초 / 쿨다운 10초 | 첫 유효 타격 1회 방어 |
| 오인 공격 | 3초 기절 | NPC를 잘못 공격한 경우 |
| 유물 습득·등록·탈취 | 각 2초 | 서버 승인 필요 |
| 등록 보호 | 5초 | 등록 수에는 포함, 탈취는 불가 |
| 최대 운반 | 1개 | 사망 시 드롭 |

## 3. 경기 진행

```text
타이틀 → 방 생성/참가 → 로비 준비 → 서버 시작 승인
→ 참가자·규칙 스냅샷 → 스폰 → 카운트다운
→ Playing → 유물 승리 또는 정규 시간 종료
                  └→ 선두 동률 → 연장전 → 최종 판정
→ 결과 → 재경기 또는 로비 복귀
```

경기 시작 때 참가자 수, 진영, 유물 수, 승리 필요 개수, NPC 수를 확정한다. 경기 도중 누군가 나가도 이 값을 다시 계산하지 않는다. 호스트 이전과 경기 중 재접속은 지원하지 않는다. 승인된 참가자가 90초 안에 경기 맵에 도착하지 않으면 경기를 중단하고 로비로 돌아간다.

## 4. 유물과 승리

| 시작 인원 | 전체 유물 | 즉시 승리에 필요한 등록 수 |
|---:|---:|---:|
| 2 | 3 | 3 |
| 3 | 4 | 3 |
| 4 | 5 | 4 |

전체 유물 수는 `시작 인원 + 1`개다. 각 진영에 1개, 중앙 공용 구역에 1개를 둔다. 승리·순위·선두 대상 판정에는 **등록된 유물 수**만 쓴다. 들고 있거나 바닥에 있는 유물은 세지 않고, 등록 보호 중인 유물은 센다.

| 종료 | 조건 |
|---|---|
| 즉시 승리 | 자기 상자에 필요한 개수를 서버에서 등록 완료 |
| 전멸 승리 | 3~4인 경기, 옵션이 켜져 있고 마지막 생존자가 1명. 2인전에서는 쓰지 않는다 |
| 정규 시간 종료 | 등록 수 단독 1위 승리, 공동 선두면 연장전 |
| 연장전 종료 | 시간 안에 승리가 없으면 등록 수를 다시 비교. 최고 수가 같으면 승자 없음 |
| 비정상 종료 | 참가자 이탈, 필수 조건 실패는 `Aborted`로 분리 |

한 프레임 안에 여러 조건이 성립할 수 있으므로 종료 판정은 서버의 단일 경로에서 한 번만 확정한다.

## 5. 유물 조작

| 입력 | 대상 | 처리 |
|---|---|---|
| `F` 길게 | 바닥·공용 유물 | 2초 유지 시 습득 |
| `F` 누름 | 진영 상자 | 상자 패널 열기 |
| `Space` 길게 | 열린 자기 상자, 유물 운반 중 | 2초 등록 |
| `Space` 길게 | 열린 상대 상자 | 2초 탈취 |
| `F` 누름 | 열린 상자 | 닫고 기본 입력 복귀 |
| `Q` 누름 | 운반 중 유물 | 내려놓기 |

유물 상태는 `PublicSpawn`, `Carried`, `Dropped`, `DepositProtected`, `Registered`다. 진행 중 입력 해제·사망·거리 이탈·시야 차단·유물 상태 변경이 생기면 서버가 상호작용을 끊는다. 두 사람이 같은 유물을 노리면 먼저 예약한 쪽만 진행한다. 상대 상자의 등록 수와 유물 운반자는 전역 HUD로 공개하지 않는다.

## 6. 이동·자세·전투

기본 이동은 걷기, 달리기, 점프다. 1인칭에서는 카메라 방향에 몸을 맞추고, 3인칭에서는 이동 방향을 바라본다. 자세 모드에서는 몸 방향을 고정하고 선택한 자세 그대로 미끄러지듯 움직인다. 자세는 기본 → 납작 → 웅크리기 → 대자 → 기본 순으로 바뀐다. 자세 중에는 공격·방어·달리기·스킬·상호작용을 쓸 수 없다.

공격은 HP를 깎지 않고 한 번의 유효 타격으로 쓰러뜨린다. 전방 범위·거리·지형 시야 조건에 맞는 대상을 모두 판정할 수 있다. 판정은 공격 애니메이션의 타격 시점에 서버가 하므로, 누르자마자 상대가 쓰러지지 않는다. 방어는 정면 한정으로 첫 유효 타격 한 번을 막는다. NPC를 공격하면 상대는 무사하고 공격자가 기절한다.

## 7. 스킬

| 스킬 | 쿨다운 | 효과 | 대상 |
|---|---:|---|---|
| 투명화 | 25초 | 5초간 몸이 보이지 않음 | 자신 |
| 발소리 증폭 | 60초 | 8초간 대상의 발소리가 나에게 크게 들림 | 다른 플레이어 |
| 시야 교란 | 600초 | 주효과 5초 | 다른 플레이어 |

상대 대상 스킬은 `LMB`로 유효 대상 중 무작위, `RMB`로 등록 유물이 가장 많은 상대를 고른다. 대상 이름·위치·진영은 알려 주지 않는다. 취소하거나 서버 검증에 실패하면 쿨다운을 쓰지 않는다. 쿨다운은 사망·기절·관전·리스폰 중에도 흐른다.

## 8. NPC와 퀘스트

NPC는 정체를 숨기기 위한 군중이다. 서버가 걷기·정지·달리기·점프·유물/상자 접근 행동을 고른다. 유물에 다가갈 수는 있지만 줍거나 등록하지 않는다. 오인 공격을 받은 NPC와 주변 NPC는 비명을 지르며 달아난다.

퀘스트는 점프 횟수, 달리기 누적 시간, 감정표현 유지, 특정 자세 유지의 네 종류다. 실제 행동을 서버가 관측해 진행도를 올린다. 제한시간을 넘기면 그 캐릭터 주변에서 3D 사이렌이 울리고, 남은 행동을 마치면 꺼진다. 퀘스트 완료 보상(쿨다운 회복)은 검토 후 제외했다. 퀘스트는 행동을 강요해 정체를 드러내게 만드는 장치로만 쓴다.

## 9. 사망·관전·리스폰

```text
0~5초   시체 중심 DeathCam
5~10초  공격자의 현재 시점
10~25초 제한된 자유 카메라
25~30초 암전과 5·4·3·2·1 카운트다운
30초    서버 리스폰 완료 후 조작 복귀
```

과거 장면을 녹화하는 Kill Replay는 쓰지 않는다. 관전 카메라는 본인 화면에서만 동작하며, 서버의 사망·리스폰 판정과 분리한다. 자유 카메라는 벽을 통과하지 않는다. 리스폰은 자기 진영에서 하고, 보호 시간 동안 공격받지 않는다.

## 10. 음성 채팅

살아 있을 때는 월드 거리 기준 근접 음성, 사망했을 때는 정상 접속한 모든 플레이어의 음성을 거리와 관계없이 듣는다. 음성은 정체를 판별하는 단서이므로 이름·발화 아이콘·음원 방향 UI는 표시하지 않는다. 마이크 입력 크기는 들리는 거리를 바꾸지 않는다. 기본 청취 거리는 300cm 안 최대 음량, 2,500cm 밖 무음이다.

## 11. 화면·연출

- 주요 화면: 타이틀, 메인 메뉴, 로비, 경기 HUD, 상자 패널, 스킬 대상 선택, 퀘스트·이벤트, 관전, 경기 결과, 공통 설정.
- 경기 결과: 승패 제목, 참가자 이름·등수·누적 획득 유물 수·킬 수. 등수는 종료 시 등록 수 기준이고 공동 순위를 허용한다. 전멸 승리일 때만 승자를 1위로 고정한다.
- 후반 공개: 정규 경기 종료 60초 전 3초 동안 모든 유물 위치를 공개하고, 연장전 시작 전 5초 동안 진영 문양별 등록 수를 보여 준다.
- 물리 표현: 이동 중에는 절차적 젤리 관성 애니메이션, 사망 시에만 Ragdoll.

## 12. 맵

마녀의 저택과 젤리 마을을 중심으로 한 `Horror Mansion Map`이다. 사탕·설탕 구조물, 진영별 상자, 공용 유물 구역, NPC 보행 공간을 배치한다. 진영은 BaseSlot 0~3으로 구분하고 서로 다른 문양을 쓴다. 문양과 캐릭터의 정체는 직접 연결되지 않는다. 한 진영에 시작 위치·부활 위치·상자를 둔다. 라운드 중 여닫히는 문이나 통로 봉쇄는 넣지 않는다.

## 13. 랜덤 이벤트

| 이벤트 | 진행 | 대상 |
|---|---|---|
| 젤리나라 정전 | 3초 경고, 2초 전 조명 깜빡임, 10초 | 월드 조명·시야 |
| 젤리 패닉 | NPC가 1~3초 간격으로 도주·점프·비명, 10초 | NPC 군중 |
| 젤리 전염병 | 이동 방향 입력만 반전, 10초 | 살아 있는 플레이어 |

경기 시작 후 4분·8분·12분에 발생을 시도하고, 경기마다 2~3회만 실행한다. 생존 조건이나 다른 퀘스트·이벤트와 겹치면 그 회차는 건너뛴다. 같은 이벤트를 연속으로 고르지 않는다. 정전 중에도 이동·상호작용·전투·스킬·음성은 그대로다. 입력 반전은 WASD 이동에만 적용하고 카메라·UI·공격·방어·점프에는 적용하지 않는다. 진행 중인 상호작용을 이벤트 때문에 자동 취소하지 않는다.

## 14. 공개 정보 예외

평소에는 각 진영의 등록 유물 수, 현재 운반자, 스킬 대상, 살아 있는 상대의 정체를 숨긴다. 상자 안의 수는 직접 상자를 연 플레이어에게만 보여 준다.

| 예외 | 시점 | 공개 내용 |
|---|---|---|
| 유물 위치 공개 | 정규 경기 종료 60초 전, 3초 | 상자 안·필드·공용·운반 중인 모든 유물의 **위치**. 운반자 이름은 표시하지 않음 |
| 연장전 소개 | 연장전 진입 전, 5초 | 진영 문양별 등록 수 |

공개가 끝나면 다시 숨긴다. 등록 수를 평소에 GameState에 넣어 두고 UI에서만 숨기는 구조는 쓰지 않는다. 데이터 자체를 그 시간에만 만든다.

## 15. 사운드·애니메이션 범위

| 범주 | 내용 |
|---|---|
| 캐릭터 | 발소리, 걷기·달리기, 공격·방어, 기절, 비명, 감정표현 |
| 유물 | 접근·습득·드롭·등록·탈취와 알림 |
| 스킬 | 투명화, 발소리 증폭, 시야 교란, 대상 선택 |
| 이벤트 | 정전 경고, NPC 패닉, 입력 반전 경고, 퀘스트 사이렌 |
| UI/환경 | 버튼·결과·시간 경고, 배경음악, 저택 환경음 |

애니메이션은 Idle/Walk/Sprint/Jump, 공격·방어, 자세, Dance/Laugh/Cheer, FakeDeath, 실제 사망 Ragdoll, 리스폰이다. 상자 열기·유물 습득·등록·드롭에는 별도 몽타주를 쓰지 않고 Idle을 유지한다.

## 16. 플레이테스트 관측 항목

| 영역 | 수집할 값 |
|---|---|
| 경기 | 평균 경기 시간, 정규·연장 승리 비율, 승자 없음, 연결 중단 |
| 유물 | 첫 습득 시간, 등록·탈취·드롭·복구 횟수 |
| 전투 | NPC 오인 공격률, 공격당 유효 대상 수, 방어 성공률 |
| 위장 | 상대를 알아낸 단서, NPC와 사람을 혼동한 사례, 퀘스트가 정체 노출에 준 영향 |
| 음성 | 근접 감쇠 체감, PTT, 사망·부활 전환 |

수치는 테스트 조건(Host/Client, 인원, NPC 수, 네트워크 지연)과 함께 기록한다.

## 17. 범위에서 제외한 것

- 전용 서버, 호스트 이전, 중도 참가
- NPC의 가짜 공격·가짜 죽음 행동
- 퀘스트 완료 보상
- 전신 액티브 래그돌

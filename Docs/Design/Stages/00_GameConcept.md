# 00 — 게임 콘셉트와 규칙 범위

## 게임 구조

NPC와 플레이어가 같은 젤리 인간 외형을 쓴다. 외형이나 이름으로는 상대를 구분할 수 없고, 움직임·상호작용·음성을 관찰해 판별해야 한다. 참가자마다 진영 상자가 있고, 정해진 수의 유물을 먼저 등록한 사람이 탈출한다. 2~4인 Listen Server 개인전을 기준으로 범위를 정했다.

## 처음부터 고정한 제약

- 정체 정보는 화면에서만 숨기지 않고, 필요할 때를 빼면 네트워크로도 보내지 않는다.
- 유물·전투·스킬·승패는 서버가 최종 판정한다.
- NPC는 위장용 군중이며 유물 쟁탈에 참여하지 않는다.
- 호스트 이전, 중도 참가, 경기 저장은 범위에서 뺀다.
- 연장전·관전·음성·UI·Steam은 뒤 단계에서 붙이되, 이 단계에서 데이터 소유권만 먼저 정한다.

## 초기 규칙

참가자는 2~4명, 정규 경기는 15분이다. 유물은 참가자 수 + 1개다. 2인전은 등록 유물 3개로 승리하고 전멸 승리를 쓰지 않는다. 3인은 3개, 4인은 4개가 필요하다. NPC 배율은 처음에 인원당 10명으로 잡았고, 이후 15명으로 늘렸다.

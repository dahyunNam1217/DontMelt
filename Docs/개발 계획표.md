# Don't Melt 개발 계획표

## 전체 목표

- Unreal Engine 5 C++ 기반 멀티플레이 프로젝트 구현
- 2~4인 Listen Server 구조
- 중복 기능 최소화
- 클래스·컴포넌트·데이터 책임 명확화
- Steam 패키징 및 멀티플레이 테스트
- 최종 최적화 및 프로파일링 완료
